# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting feature for this repository when available. Include a concise description, the affected version or commit, reproduction steps, and the potential impact.

This project is an offline analysis toolkit. It does not send datasets to a remote service. Users are still responsible for protecting local files, credentials, and generated reports in their own environments.

## Supported versions

Only the latest release on the `main` branch is actively maintained while the project is in the 0.x release series.
